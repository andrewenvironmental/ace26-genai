# Documentation

This directory contains public-safe workshop guidance for the ACE26 GenAI materials. The current priority is an Azure-hosted public web app, with offline notebook material retained only as a contingency path.

## Current Workshop Path

- `activity-guide.md`: participant-facing ACE26 AI Pre-conference Workshop activity.
- `playground-api-usage.md`: instructor/developer notes for how the workshop web app routes chat and search requests.
- `deployment-azure-app-service.md`: GitHub Actions, OIDC, ACR, and App Service deployment runbook.
- `azure-config-discovery.md`: safe commands for deriving real Azure and GitHub environment values.
- `demo-risk-mitigation.md`: ranked demo options and fallback guidance.
- `sample-output-fort-worth-cip.md`: static sample output for low-connectivity discussion.

## Repo Organization

- `repo-organization.md`: recommended structure, documentation ownership, and retirement candidates as the project moves toward the Azure public web app.
- `open-source-playground-template-research.md`: background research for the compact custom web app direction.
- `pr-description-issue-1.md`: historical PR description draft; keep only while useful for issue/PR tracking.

## Legacy Contingency Path

- `colab-fallback.md`: last-resort notebook runbook for offline delivery.
- `../notebooks/README.md`: notebook status and safety notes.

The Colab notebook should not be promoted as the default attendee path in new workshop materials.
